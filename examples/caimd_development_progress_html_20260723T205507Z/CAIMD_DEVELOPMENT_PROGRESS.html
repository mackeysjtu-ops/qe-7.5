3科学动机 Scientific Motivation

普通 Parrinello–Rahman（PR）vc-md 允许模拟胞在内应力与外压驱动下自由弛豫：胞的九个自由度都由 PR 运动方程演化。而定量的加载 / 变形协议需要相反的能力——选定的应变分量必须跟随外部施加的时间表（例如以固定应变率单轴压缩 xx），同时：

  • 其余未指定的应变分量保留普通 PR 响应（例如横向法向分量按泊松效应自由弛豫）；
  • 离子受力与 DFT 应力张量仍然是普通 QE 量——CAIMD 不修改 forces.f90 / stress.f90 / pwcom.f90；
  • CAIMD 约束的是由此产生的胞运动（对 PR 候选胞做投影），而不是替换力或应力模型。

目标系综因此是：thermostatted constrained-strain Parrinello–Rahman dynamics（受热浴控制的约束应变 PR 动力学）。它不是无约束完整 NpT：被掩码的应变分量由外部时间表驱动做功，系统处于驱动非平衡协议之下，只有离子子系统由 Nose-Hoover 链控温。

应用背景（见 examples/iceX_100GPa_300K_caimd）：Ice X 在 100 GPa、300 K 下的受控拉伸 / 压缩 / 剪切响应，以及 Diamond 的有限应变率加载。

4原始 QE vc-md 架构

以下调用路径已对照 af7ebfc 源码逐一核实（文件与行号见图 1 底注）：

  1. PW/src/run_pwscf.f90：每个离子步完成电子自洽，调用力与应力计算；XML step 输出发生在 move_ions 之前。
  2. PW/src/move_ions.f90（基线未修改）：calculation='vc-md' + cell_dynamics='pr' 被 input.f90 映射为 calc='cd'，分派到 vcsmd。固定胞 Langevin 分支（calc(1:1)=='l'）与 vc-md 无关。
  3. PW/src/vcsmd.f90：把 PW 笛卡尔位置 / 力转换为晶格坐标，桥接 PR 状态与 MD 历史文件 tmp_dir/prefix.md。
  4. 第 1 个离子步走 PW/src/vcsubs.f90:vcinit（含自有的速度生成路径，见 §12）；之后各步走 vcsubs.f90:vcmove（Beeman 预测-校正 PR 积分器）。
  5. 每步结束提交原子与胞历史：.md（积分器状态）、.cel/.pos/.vel/.for（轨迹）、.e/.eal/.ave/.p/.tv（能量 / 温度诊断）。

关键状态变量（vcsubs.f90 内部约定）

变量含义
rat晶格（分数）坐标下的原子位置
rati上一步原子位置（Beeman 历史）
ratd晶格坐标下的原子速度类历史；物理笛卡尔速度 = avec · ratd

要点：MD 历史是物理积分器状态的一部分。Beeman 更新同时使用当前与上一步的加速度，且 PR 度规耦合把胞速度 / 加速度历史直接注入原子加速度更新。因此任何对返回胞矩阵的"仅投影"都不完整——投影必须一致地作用于全部历史（这正是 CAIMD V1 的做法，§5）。也因此，仅凭输入卡片无法构造精确延拓（§12）。

5CAIMD 设计与实现

输入接口（&CELL namelist，已在源码中核实）

变量类型 / 默认值语义
caimdLOGICAL，默认 .FALSE.总开关；.FALSE. 时必须是精确 no-op
caimd_strideINTEGER，默认 1，必须 > 0事件间隔：每 stride 个离子步施加一次应变事件
caimd_step_strain(6)REAL(DP)，默认 0.0每步名义应变增量（事件增量 = stride × step_strain）
caimd_mask(6)LOGICAL，默认 .FALSE..TRUE. 分量受控 / 保持；.FALSE. 分量保留 PR 响应
  • 分量顺序：(xx, yy, zz, yz, xz, xy)。
  • 剪切约定：非对角分量为张量剪切；工程剪切 = 2 × 张量剪切（.caimd 文件头亦有声明）。
  • 事件时间表：事件步满足 MOD(istep−1, caimd_stride) == 0——第一事件约定：第 1 个离子移动即为事件。
  • strain-and-hold：非事件步掩码分量被保持在当前累计名义值；未掩码分量每步都取 PR 候选响应。
  • 累计目标：掩码目标相对运行开始记录的参考胞 H_ref 累计（H_new = (I + E_new)·H_ref），避免逐步 (I+δE) 连乘漂移。
  • 安全检查：每事件增量硬限制 |stride·step_strain| ≤ 1.0e-2；投影胞行列式下限与条件数上限检查，失败即显式报错停止（0.30 轨迹正是这样终止的，§10.1）。

数学描述

F      = H_candidate · H_ref⁻¹              # 相对参考胞的变形梯度
E_pr   = ½ (F + Fᵀ) − I                     # 对称小应变；反对称部分 W 被丢弃（抑制胞转动）
target(i) += stride · step_strain(i)         # 仅事件步、仅掩码分量
E_proj(i) = mask(i) ? target(i) : E_pr(i)    # 掩码分量受控，未掩码分量保留 PR 响应
H_projected = (I + E_proj) · H_ref           # 重构投影胞（安全检查后提交）
T = H_projected⁻¹ · H_candidate              # 速度基底变换
ratd, rat2d, rat2di ← T · (·)                # 保持物理笛卡尔速度 u = H·ratd 与分数位置
avecd, avec2d, avec2di ← 掩码分量置零的对称 tangent 投影

事实 / 设计选择 / 局限的区分

实现事实（源码核实）

  • 投影插入点在 vcsubs.f90 PR/Beeman 路径内（vcinit 383-385 行、vcmove 735-737 / 857-870 / 1123-1152 行）。
  • 力与应力计算完全未修改（forces.f90、stress.f90、pwcom.f90 与基线相同；git diff 证实）。
  • .caimd 为 26 列 premove 诊断流，仅 I/O rank 写出。
  • 压力路径不变：press（GPa）→ press_ = press / ry_kbar。

设计选择

  • 小应变度量 E = sym(F−I) 而非有限应变；累计目标锚定参考胞。
  • 反对称增量完全抑制（实验室系不转动）。
  • 保持物理笛卡尔速度而非晶格速度不变。
  • 第一事件在第 1 步（而非先自由弛豫一段）。

当前局限

  • V1 是小应变协议，不是有限应变本构框架；大累计应变（>1e-2）只发一次性警告。
  • restart 不支持（§12）；无 XML/QEXSD 集成；无 PW/Doc 用户文档。
  • 固定原子坐标（if_pos≠1）与 active CAIMD 组合被显式拒绝。
  • CP 不实现 CAIMD；CP 输入中 caimd=.true. 显式报错。

6Thermostat 集成

THERMOSTAT_CAIMD_AUDIT.md 的源码审计结论（已对照 af7ebfc 源码复核）：

  • PW vc-md 不使用固定胞 MD 的 dynamics_module.apply_thermostat 分派。move_ions.f90 只在 calc(1:1)=='l'（固定胞 Langevin）时走 langevin_md；vc-md/PR 永远进入 vcsmd。
  • Nose 是唯一在真实 vcsmd/vcsubs 调用图中显式集成的持续热浴：input.f90 置 tnosep=.true.；vcsmd 在 vcmove 前调 ions_nosevel、后调 ions_noseupd；vcmove 内摩擦项 rat2d ← rat2d − vnhp·ratd 作用于离子速度历史（vcsubs.f90:708-715）。
  • 其他 ion_temperature 关键字不是真实的 vc-md 路径：berendsen/svr/andersen/rescale-v/rescale-T/reduce-T 只被固定胞 dynamics_module 消费；rescaling 在 vcmove 中会同时重标 ratd 和 avecd（污染 PR 胞速度）；initial 只是初始化不是持续热浴；Langevin 在 vc-md 不可达。

白名单（PW/src/input.f90:1739-1756，源码核实）

输入active CAIMD 下的处理
ion_temperature='not_controlled'（及连字符 / 空格变体）允许 无离子热浴
ion_temperature='nose'允许 既有 PW vc-md Nose-Hoover 路径
其余全部 ion_temperature 模式拒绝 errore：active CAIMD supports only ion_temperature='not_controlled' or 'nose'
cell_temperature ≠ not_controlled拒绝 胞热浴不支持

Nose 与 CAIMD 投影的耦合（源码核实）

  • Nose 作用位置：摩擦项在 vcmove 内直接作用于晶格坐标离子速度历史 ratd（通过 rat2d 更新），发生在 CAIMD 最终投影之前。
  • 为什么投影必须保持物理笛卡尔速度：投影改变胞基底 H；若 ratd 不做 H_projected⁻¹·H_candidate 变换，物理速度 u = H·ratd 会在每个事件步发生非物理跳变，等效于对系统做隐性冲击 / 加热。
  • 为什么投影后要重算离子动能：Nose 链更新消费动能 ekin2nhp。CAIMD 投影后 vc_refresh_projected_energies 以最终投影胞与变换后 ratd 重算 eka / 温度，tnosep 时 vc_refresh_projected_nose_ekin 同步刷新 ekin2nhp（vcsubs.f90:1143-1152, 1245-1278），保证热浴更新与提交的 MD 历史引用同一物理速度状态。
  • .caimd 的 temperature_K：取自最近一次完成移动的离子动能（ndof = 3(N−1) = 21），不含 PR 胞动能；首行在积分器历史建立前回退为输入目标温度。

边界声明：以上确认的是输入路径、调用图与动能同步逻辑的实现正确性，以及短程 smoke 通过。本节不声称长时间 Nose 控温已验证——事实上长时间行为当前失败（§10、§11）。

10失败与受阻证据

10.1 大应变 Diamond8 连续加载（本地，rate 0.05 ps⁻¹，目标 −0.30）

  • 掩码 xx 投影全程精确（≤ 2.26e-16，图 4）；速度残差 ≤ 1.64e-14。
  • 但未掩码胞自由度失稳：~0.37 ps 起 zz/xz/yy/yz/xy 依次越过 0.05 → 0.1 → 0.25 → 0.5，终态 |分量| 高达 1.08（图 9）；第 265 步 QE 以 Error in routine caimd_inverse3 (1): caimd projected cell is singular 显式终止。
  • 末行 CAIMD 温度 ~7.0e10 K、压力 ~11777 kbar、最小 C-C 距离 0.256 bohr——轨迹早已非物理。
  • 解读：0.05 ps⁻¹ 的激进速率 + 大残余应力使该设置不适合用于热浴验证；这是安全检查按设计工作的例证，同时暴露未掩码 PR 分量在该参数域的失稳。升温本身在第 3 步就已出现（90978 K @ 0.004 ps），远早于胞畸变——与 §11 的基线问题一致。

12初速度与延拓问题

源码观察（af7ebfc，vcsubs.f90:190-260）

  • 第一 vc-md 步中 vcinit 拥有自己的速度生成路径：仅当 input_velocities_read（需要 ion_velocities='from_input' + ATOMIC_VELOCITIES { a.u } 卡片，且经 vcsmd 桥接——该桥接是 1f1f16d 引入的本仓库修改）时才消费输入速度；否则调用 ranv(temp, …) 按目标温度生成 Maxwell 分布。pristine QE 7.5 的 vc-md 总是走 ranv 路径。
  • 因此：输入文件中存在直接温度为 300 K 的速度块，不能证明积分器消费了该速度块。
  • 同样：首行 .eal 温度接近 300 K 也不能证明输入速度被使用——tempw=300 会使 ranv 生成的内部速度落在同一目标附近。

推论

  • 对干净的普通 from-scratch 基线（§15 优先级 1）：省略 ATOMIC_VELOCITIES 是合理的——让两个可执行程序各走原生初始化，避免把速度路径差异混入对照。
  • 对声称精确的 Stage-1 → Stage-2 延拓：省略速度不可接受；且外部 restart_mode='from_scratch' 延拓在证明输入速度确被消费之前，不能称为动力学精确。此外 Beeman 历史（rat2di 等）与 Nose 链状态（xnhp0/xnhpm/xnhpp/vnhp）无法通过输入卡传递——外部延拓在原理上就不是精确 Nose 扩展态重启。
  • native CAIMD restart 当前不支持（V1 显式拒绝 restart_mode='restart' 与陈旧 MD 历史）。
建议的最小速度消费测试（V0/V1/V2）：
  1. V0：不含 ATOMIC_VELOCITIES；
  2. V1：显式速度卡；
  3. V2：符号反转的显式速度卡；
  4. 比较三者第一条提交的 .md 中的 ratd：若 V1 与 V2 给出反号的确定性 ratd 而 V0 给出随机分布，即证明消费；若三者统计相同，即证明未消费；
  5. 对 pristine QE 7.5 与 af7ebfc 都执行。
