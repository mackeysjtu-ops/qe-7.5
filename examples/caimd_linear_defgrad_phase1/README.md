# CAIMD Linear Deformation-Gradient Phase 1 Fragments

These are non-production `&CELL` fragments for the Phase 1
`caimd_loading_mode='linear_defgrad'` interface.  They are documentation
examples only and were not executed as AIMD validations.

The input structure must be pre-oriented outside QE so the intended local axes
coincide with QE Cartesian axes.  QE does not parse Miller indices or rotate the
structure for this mode.
