# Parameter Selection

This file records the parameter rationale used to prepare the bounded Ice X
CAIMD example. Values marked tentative must be updated after Leonardo validation
jobs complete.

## Structure

- Source file: local `iceX.data`.
- Source SHA256: `103ccf1fe76e3b3a737914a4eeddb4016d6fb8b308129516541ddc5de08aa6c6`.
- Atom count: 144 total, O=48, H=96.
- Cell: orthorhombic, rows in Angstrom:
  - `9.2145100000 0.0000000000 0.0000000000`
  - `0.0000000000 6.5156430000 0.0000000000`
  - `0.0000000000 0.0000000000 7.5236160000`
- Volume: `451.706300063683 Angstrom^3`.
- Density under Angstrom interpretation: `3.178909003080 g/cm^3`.
- The conversion applies no rotation, symmetrization, relaxation, or atom-order
  changes.

## Pseudopotentials

Remote UPF files:

- H: `/leonardo/home/userexternal/mcheng00/psd/H.upf`
- O: `/leonardo/home/userexternal/mcheng00/psd/O.upf`

Both are PBE PAW/USPP-compatible UPF v2.0.1 files generated by ATOMPAW. No UPF
contains a machine-readable recommended cutoff, so the example uses bounded
cutoff testing rather than claiming a pseudopotential-provided cutoff.

The initial `ecutrho/ecutwfc` ratio is `8`, selected because the QE input
documentation notes that USPP-like datasets often need a larger charge-density
cutoff than the norm-conserving default. This is a conservative starting point
for the PAW/USPP flags in these UPFs, not a convergence result.

## Pressure

Target pressure is `100 GPa`.

QE PW input documentation for `press` states the unit is kbar. The PW source
converts with `press_ = press / ry_kbar`, and `ry_kbar` is the internal
Ry/bohr^3 to kbar conversion. Therefore this example uses:

```text
press = 1000.0
```

because `100 GPa = 1000 kbar`.

Note: the local `CAIMD_IMPLEMENTATION.md` pressure paragraph says GPa, which is
inconsistent with QE PW input documentation and the source conversion path. This
example follows the QE input documentation plus `PW/src/input.f90`.

## Time Step

PW `dt` is in Rydberg atomic time units. QE prints femtoseconds as:

```text
dt_fs = dt * 2.0e3 * au_ps
```

so `dt=5.0` corresponds to approximately `0.241889 fs`.

Bounded dt/wmass pilot cases:

- `dt=5.0`, `wmass=65.7122994644 amu`
- `dt=7.5`, `wmass=65.7122994644 amu`
- `dt=10.0`, `wmass=65.7122994644 amu`
- `dt=5.0`, `wmass=32.8561497322 amu`
- `dt=5.0`, `wmass=131.4245989289 amu`

Tentative final value before pilot validation: `dt=5.0`.

## Cell Mass

For Parrinello-Rahman `vc-md`, QE derives the default `wmass` as:

```text
wmass_default = 0.75 * total_atomic_mass / pi^2
```

The converted Ice X cell has total mass `864.739200000004 amu`, so:

```text
wmass_default = 65.7122994644 amu
```

The final templates set this value explicitly for reproducibility.

## CAIMD Strain Schedule

CAIMD component order is:

```text
(xx, yy, zz, yz, xz, xy)
```

The final manual-submit templates use:

- `caimd_stride=5`
- `caimd_step_strain=5.0d-5` on the masked component
- per-event increment `stride * step = 2.5d-4`
- `nstep=100`
- expected event count: 20
- final nominal tensor strain magnitude: `0.005` on the masked component

For shear, the masked component is tensor `xy`; engineering shear is twice the
reported tensor shear, so the final nominal engineering shear is `0.010`.

These schedules are deliberately small pilot-scale deformations. They are not a
publication strain-rate claim.
