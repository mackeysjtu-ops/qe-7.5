# Pseudopotentials

This example does not store UPF binaries in Git. On Leonardo, create symlinks in
this directory:

```bash
ln -sfn /leonardo/home/userexternal/mcheng00/psd/H.upf H.upf
ln -sfn /leonardo/home/userexternal/mcheng00/psd/O.upf O.upf
```

The Slurm scripts require those symlinks and verify the custom CAIMD `pw.x`
checksum before execution.

Use only these remote source files for this example:

- `/leonardo/home/userexternal/mcheng00/psd/H.upf`
- `/leonardo/home/userexternal/mcheng00/psd/O.upf`

Do not substitute nearby or unrelated files such as `1.2m_compress.pb`.

Remote metadata verified during preparation:

- H: UPF version 2.0.1, generated by ATOMPAW, PBE, scalar relativistic,
  `pseudo_type="PAW"`, `is_ultrasoft="T"`, `is_paw="T"`, `z_valence=1.000`.
- O: UPF version 2.0.1, generated by ATOMPAW, PBE, scalar relativistic,
  `pseudo_type="PAW"`, `is_ultrasoft="T"`, `is_paw="T"`, `z_valence=6.000`.

No machine-readable recommended cutoff was found in either UPF; cutoff values
are therefore selected through the bounded convergence matrix.
